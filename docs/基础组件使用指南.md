# WibotLib 基础组件使用指南

## 概述

WibotLib 的 `base` 目录提供了嵌入式开发所需的一系列基础类和工具，包括类型系统、时间处理、缓冲区管理、数学运算等。这些组件是整个库的基石，为上层模块提供统一、高效的基础功能。

**文件位置**：[libs/wibotlib/src/base/](../src/base/)

## 1. 类型系统 (type.hpp)

### 1.1 基础类型定义

WibotLib 定义了一套统一的类型别名，确保跨平台的一致性和代码可读性：

```cpp
#include "type.hpp"

// 无符号整数
using u8  = uint8_t;   // 8位无符号整数
using u16 = uint16_t;  // 16位无符号整数
using u32 = uint32_t;  // 32位无符号整数
using u64 = uint64_t;  // 64位无符号整数

// 有符号整数
using i8  = int8_t;    // 8位有符号整数
using i16 = int16_t;   // 16位有符号整数
using i32 = int32_t;   // 32位有符号整数
using i64 = int64_t;   // 64位有符号整数

// 浮点数
using f32 = float;     // 32位浮点数
using f64 = double;    // 64位浮点数
```

**使用示例**：
```cpp
u16 adcValue = 0;
i32 temperature = -25;
f32 voltage = 3.3f;
```

### 1.3 Result 错误处理机制

`Result` 类提供统一的错误处理机制，避免使用异常：

#### 错误状态枚举
```cpp
enum class ResultStatus : u8 {
    kOk               = 0x00U,  // 成功
    kError            = 0x01U,  // 通用错误
    kBusy             = 0x02U,  // 设备忙
    kTimeout          = 0x03U,  // 超时
    kInvalidParameter = 0x84U,  // 无效参数
    kNoResource       = 0x85U,  // 资源不足
    kNotSupport       = 0x86U,  // 不支持
};
```

#### 使用方法
```cpp
#include "type.hpp"
using namespace wibot;

// 函数返回 Result
Result initDevice() {
    if (deviceNotFound) {
        return Result::kError;
    }
    if (parameterInvalid) {
        return Result::kInvalidParameter;
    }
    return Result::kOk;
}

// 错误检查
void myFunction() {
    Result result = initDevice();
    
    if (result.isOk()) {
        // 成功处理
    } else if (result.isTimeout()) {
        // 超时处理
    } else if (result.isError()) {
        // 错误处理
        u32 errorCode = result.getErrorCode();
    }
}

// 简洁写法
if (initDevice() != Result::kOk) {
    // 错误处理
}
```

#### 常用方法
```cpp
bool isOk() const;       // 是否成功
bool isError() const;    // 是否错误
bool isBusy() const;     // 是否忙
bool isTimeout() const;  // 是否超时
u32 getErrorCode() const; // 获取错误代码
```

## 3. 缓冲区 (buffer.hpp)

### 3.1 Slice - 动态缓冲区切片

`Slice` 提供对任意内存区域的安全访问，支持多种数据类型的读写。

#### 构造方法
```cpp
Slice(u8 &data);                    // 单字节
Slice(u16 &data);                   // 16位数据
Slice(u32 &data);                   // 32位数据
Slice(u64 &data);                   // 64位数据
Slice(i8/i16/i32/i64 &data);        // 有符号整数
Slice(float &data);                 // 浮点数
Slice(u8 *data, u16 size);          // 任意缓冲区
```

#### 基本操作
```cpp
void clear();  // 清空缓冲区

// 成员变量
u8  *data;     // 数据指针
u16 size;      // 数据大小
```

#### 数据读写（支持大小端）
```cpp
// 8位
u8   getUint8(u16 index) const;
void setUint8(u16 index, u8 value) const;
i8   getInt8(u16 index) const;
void setInt8(u16 index, i8 value) const;

// 16位
u16  getUint16(u16 index, Endian endian = Endian::kBig) const;
void setUint16(u16 index, u16 value, Endian endian = Endian::kBig) const;
i16  getInt16(u16 index, Endian endian = Endian::kBig) const;
void setInt16(u16 index, i16 value, Endian endian = Endian::kBig) const;

// 32位
u32  getUint32(u16 index, Endian endian = Endian::kBig) const;
void setUint32(u16 index, u32 value, Endian endian = Endian::kBig) const;
i32  getInt32(u16 index, Endian endian = Endian::kBig) const;
void setInt32(u16 index, i32 value, Endian endian = Endian::kBig) const;

// 浮点数
f32  getFloat(u16 index, Endian endian = Endian::kBig) const;
void setFloat(u16 index, f32 value, Endian endian = Endian::kBig) const;
```

#### 使用示例
```cpp
u8 buffer[64];
Slice slice(buffer, 64);

// 写入不同类型的数据
slice.setUint8(0, 0x42);
slice.setUint16(1, 0x1234, Endian::kBig);   // 大端序
slice.setUint32(3, 0x12345678, Endian::kLittle); // 小端序
slice.setFloat(7, 3.14159f);

// 读取数据
u8  val8  = slice.getUint8(0);
u16 val16 = slice.getUint16(1, Endian::kBig);
u32 val32 = slice.getUint32(3, Endian::kLittle);
f32 valf  = slice.getFloat(7);

// 清空
slice.clear();
```

**应用场景**：
- 串口/网络协议数据包的编解码
- 与外部设备通信时处理不同字节序
- 在固定内存区域上安全地读写多种数据类型

### 3.2 Buffer - 静态缓冲区模板

`Buffer` 是固定大小的静态缓冲区模板，提供编译时类型安全。

#### 定义
```cpp
template <u16 CAP, typename T = u8>
struct Buffer {
    u16 size = CAP;       // 当前使用大小
    T   data[CAP];        // 数据数组
    
    constexpr static u16 cap = CAP;  // 编译时容量
    
    operator Slice();     // 转换为 Slice
    Slice toSlice(u16 length, u16 offset = 0);  // 部分切片
    T &operator[](u32 index);  // 数组访问
};
```

#### 使用示例
```cpp
// 定义不同类型的缓冲区
Buffer<128> byteBuffer;           // 128字节缓冲区
Buffer<64, u16> wordBuffer;       // 64个u16缓冲区
Buffer<32, f32> floatBuffer;      // 32个f32缓冲区

// 数组访问
byteBuffer[0] = 0x42;
byteBuffer[1] = 0x43;

wordBuffer[0] = 1234;
floatBuffer[0] = 3.14f;

// 转换为 Slice
Slice slice = byteBuffer;  // 隐式转换

// 部分切片
Slice partialSlice = byteBuffer.toSlice(16, 8);  // 从偏移8开始的16字节

// 获取容量
constexpr u16 capacity = Buffer<128>::cap;  // 编译时常量
```

**优势**：
- 编译时确定大小，无运行时开销
- 类型安全
- 可自动转换为 Slice 使用其丰富的读写方法

**应用场景**：
- DMA 传输缓冲区
- 通信协议数据包缓冲
- 传感器数据采样缓冲

## 6. 最佳实践

### 6.1 类型使用建议

1. **优先使用 WibotLib 类型别名**
   ```cpp
   // ✅ 推荐
   u32 count = 0;
   f32 voltage = 3.3f;
   
   // ❌ 不推荐
   unsigned int count = 0;
   float voltage = 3.3f;
   ```

2. **使用 Result 替代异常**
   ```cpp
   // ✅ 推荐
   Result init() {
       if (failed) return Result::kError;
       return Result::kOk;
   }
   
   // ❌ 避免使用异常（嵌入式系统）
   void init() {
       if (failed) throw std::runtime_error("Init failed");
   }
   ```

### 6.2 缓冲区使用建议

1. **优先使用 Buffer 进行静态分配**
   ```cpp
   // ✅ 推荐（编译时分配）
   Buffer<128> rxBuffer;
   
   // ❌ 避免动态分配
   u8 *buffer = new u8[128];  // 嵌入式系统避免使用 new
   ```

2. **使用 Slice 处理不同字节序**
   ```cpp
   Slice slice(buffer, size);
   
   // 网络字节序（大端）
   u16 port = slice.getUint16(0, Endian::kBig);
   
   // 本地字节序（小端）
   u32 value = slice.getUint32(2, Endian::kLittle);
   ```

### 6.3 数学运算建议

1. **使用向量简化多维数据处理**
   ```cpp
   // ✅ 推荐
   Vector3f position;
   Vector3f velocity;
   position += velocity * deltaTime;
   
   // ❌ 繁琐
   position_x += velocity_x * deltaTime;
   position_y += velocity_y * deltaTime;
   position_z += velocity_z * deltaTime;
   ```

2. **使用数学常量提高可读性**
   ```cpp
   // ✅ 推荐
   f32 halfCircle = kPI;
   f32 fullCircle = k2PI;
   
   // ❌ 硬编码
   f32 halfCircle = 3.14159f;
   f32 fullCircle = 6.28318f;
   ```

## 7. 性能考虑

### 7.1 编译时计算

- `Buffer` 的容量是编译时常量，编译器可以优化
- 使用 `constexpr` 的数学常量不占用运行时内存

### 7.2 内存效率

- `Slice` 只存储指针和大小，开销极小（3字节）
- `Buffer` 无额外开销，仅包含数据数组
- 向量类型紧凑排列，无虚函数开销

### 7.3 零开销抽象

- `Result` 只使用32位存储，与返回整数相同开销
- 内联函数（如数学运算）无函数调用开销
- 模板在编译时展开，无运行时多态开销
